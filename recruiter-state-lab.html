What this proves.

01

Status is perceivable

Loading and failure use semantic status/alert feedback, not colour alone.

02

Context survives failure

Error recovery does not throw away filters, entered checkout data or the user's place in the journey.

03

Next action is explicit

Empty, error and success each answer the same question: what can I do now?

04

Touch and keyboard count

Interactive affordances use native controls, visible focus and minimum mobile targets.
